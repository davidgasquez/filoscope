01 Ask your agent

Give your coding agent the Filoscope skill and a question. Start with this:

Agent prompt 
Read and follow https://davidgasquez.github.io/filoscope/SKILL.md.
Use Filoscope to explain how Filecoin storage providers prove storage over time.
Retrieve the relevant sources and cite their canonical URLs.

The skill explains how to pull the published QMD index, retrieve documents, and cite original sources. It’s plain Markdown, ready for your agent to read.

02 Search locally

Prefer the terminal? Install the published index, then query it from any directory.

Pull the index 
npx -y --allow-remote=all filoscope pull
Ask a question 
npx -y --allow-remote=all -p filoscope qmd --index filoscope query 'how do storage providers prove storage over time'

Requires Node.js 22.21.1 or later. Retrieval runs locally with QMD; Filoscope publishes the index. See the README to materialize source files yourself.
